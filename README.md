# Food Safety Inspection Portal

This is the main page of the portal. Its styles and app behavior are in `portal.css` and `portal.js`.

## Open it

- On your computer: open `index.html` in a web browser.
- On GitHub Pages: publish the repository from the `main` branch and open the `food-safety-portal/` folder in the published site.

The demo keeps its records in the current browser's local storage. It does not sync data between browsers or devices.
